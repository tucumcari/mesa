

### Setup

```shell
wget https://github.com/rust-lang/mdBook/releases/download/v0.4.43/mdbook-v0.4.43-x86_64-unknown-linux-gnu.tar.gz
tar xvf mdbook-v0.4.43-x86_64-unknown-linux-gnu.tar.gz
rm mdbook-v0.4.43-x86_64-unknown-linux-gnu.tar.gz
./mdbook init

npm install
```

### Usage

```shell
./mdbook serve
# edit, commit, push
```
